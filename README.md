# e-plantShopping

Paradise Nursery is a front-end shopping application for houseplants.  
The application allows users to browse different categories of plants, add items to a shopping cart, and manage cart quantities before checkout.

## Features
- Landing page with background image and company introduction
- Product listing page with multiple plant categories
- Add to Cart functionality using Redux
- Shopping cart with quantity control and total price calculation
- Responsive design

## Technologies Used
- React
- Redux Toolkit
- JavaScript
- HTML
- CSS

## Project Purpose
This project is developed as the final assignment for a front-end development course to demonstrate React and Redux fundamentals.
